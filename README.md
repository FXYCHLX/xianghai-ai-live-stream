# 向海 · AI 数字人直播（移动端）

把「主播」从人力成本变成软件成本。

一套能自己开播、自己写话术、自己回答弹幕的 AI 数字人直播系统，专给中小渔户和合作社用。选商品、点开播，剩下交给程序。

## 它解决了什么

中小渔户做直播，卡在四件事上：

| 卡点 | 实际情况 |
|---|---|
| 请不起 | 一个主播一场几百到几千，渔户卖的那点货撑不住 |
| 播不动 | 没流量，两小时进不了几个人 |
| 人留不住 | 主播会离职、会涨价，粉丝还可能被带走 |
| 内容跟不上 | 写话术、做图、剪视频，渔民干不了这套活 |

平台把这几件事拆开，用程序各顶掉一块。

## 四项能力

| 能力 | 说明 | 入口 |
|---|---|---|
| **数字人 24 小时在播** | AI 生成的男主播形象，配闭嘴 / 张嘴两帧，按语音节奏切换；配音走**两级降级**：服务端微软 Edge TTS（云希男声）→ 不可用时回落浏览器原生语音合成，断网也能出声 | `/live` |
| **AI 现写话术** | 大模型结合商品价格、产地、人群实时生成「开场–痛点–卖点–促单」四段口播稿，不是预录循环 | `/live` |
| **AI 现场答疑** | 弹幕提问当场回答；答不上来会诚实说「这个我帮您问一下」，不硬编 | `/live` |
| **AI 导购** | 说需求（预算 / 用途 / 送谁），结合在售商品库给建议，推荐结果以商品卡片推到对话里 | 底部导航「客服」 |

商品库是 30 款连江海产，覆盖 6 个产地节点：黄岐半岛鲍鱼、官坞海带、晓澳缢蛏、定海湾生蚝、马鼻淡菜、坑园大黄鱼。

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配大模型（不配也能跑，AI 相关功能自动降级并明确提示，不会白屏）
#    复制 server/.env.example 为 server/.env，填入 AI_API_KEY

# 3. 一键起前后端
npm run dev:all

# 4. 打开 http://localhost:5173
#    建议 F12 切手机视图（iPhone 尺寸）
```

分开启动也行：

```bash
npm run server   # AI 服务，端口 3001
npm run dev      # 前端，端口 5173
```

**直播间演示**：`http://localhost:5173/live?demo=1` 自动开播；加 `&auto=1` 循环带货，录演示视频用这个。

### 换模型

`server/.env` 里改 `AI_BASE_URL` / `AI_MODEL`，任何 OpenAI 兼容接口都能用：

| 平台 | AI_BASE_URL | 对话模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |

## 工程上的几个关键决定

**商品数据单一来源。** 30 款商品统一在 `src/data/goods.js`，同时作为 AI 的「可售商品库」注入提示词 —— 一份数据两处使用，改一处全站同步。

**Key 不出现在浏览器。** 模型调用全部由 `server/` 转发，前端只请求 `/api/*`，Vite 代理到本地服务。API Key 只存在 `server/.env`，该文件不随源码外发。

**模型输出要校验。** 模型有时会推荐不存在的商品 ID，`server/index.js` 里对返回 ID 逐个比对商品库，编造的直接丢弃。

**图片全部本地化。** 主播形象与海产图均为 AI 生成后本地处理（去水印、抠图、转 WebP），无外链、无版权风险，断网也能完整演示。

**AI 不可用要能降级。** 模型超时或没配 key 时，自动退回静态话术并明确提示，保证演示不翻车。

## 已知限制（诚实版本）

- **口型是双帧切换驱动，不是音素级同步。** 主播形象只有闭嘴、张嘴两张图，按语音节奏随机切换（张嘴 130–280ms、闭嘴 80–210ms），观感自然但做不到逐音素对齐。
- 配音走浏览器原生语音合成，音色取决于用户设备上装了哪些中文语音包。
- 商品、订单、用户均为演示数据，无真实后端与支付。
- AI 回复依赖网络与模型服务，首次响应通常 1–3 秒。
